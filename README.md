## 📖 Overview

**PhoneInfoga** is one of the most advanced open-source intelligence (OSINT) tools for scanning international phone numbers. Written in Go (Golang), it enables researchers, security professionals, and analysts to gather intelligence, validate number syntax, identify telecom operators/carriers, and uncover digital footprints across open search engines and public directories.

---

## 🚀 Key Features

* **Number Validation & Normalization:** Checks validity, international formatting (E.164), country code, and regional prefixes.
* **Carrier & Line Type Detection:** Gathers telecom operator info and detects line types (Mobile, Landline, VoIP).
* **Automated OSINT Footprinting:** Generates Google Dorks to locate references across social networks, leaked document archives, and paste sites.
* **Built-in Graphical Web UI:** Includes a standalone web server with a browser dashboard for visual scanning.
* **Prebuilt Windows Binary:** Ships with a ready-to-use executable (`bin/phoneinfoga.exe`) — no Go installation or compilation required.
* **REST API:** Supports programmatic scanning and automation workflows.

## 💻 Quick Start & Execution Guide

This repository contains a precompiled 64-bit Windows binary inside the `bin/` directory (`bin/phoneinfoga.exe`).

### Method 1: Graphical Web Dashboard (Recommended)

1. Open PowerShell or Command Prompt in the repository folder and execute:
   ```powershell
   .\bin\phoneinfoga.exe serve -p 5050
   ```
   *(Note: Port 5050 is recommended to avoid conflicts with port 5000).*

2. Open your web browser and navigate to:
   ```
   http://localhost:5050
   ```

3. Enter the target phone number including country code (e.g., `+916351160293`) and click **Scan**.

---

### Method 2: Command Line Interface (CLI)

To scan directly from the terminal without launching the web server:

```powershell
.\bin\phoneinfoga.exe scan -n "+91XXXXXXXXXX"
```

**Example:**
```powershell
.\bin\phoneinfoga.exe scan -n "+916351160293"
```

## 🔍 Understanding "No Results Found" (OSINT vs. Aggregators)

When reviewing search queries generated by the tool, you may encounter **"No results found"** for specific queries (such as Facebook or social media lookups). This is standard behavior and does not mean the tool is malfunctioning:

1. **Private Phone Numbers:** If an individual has not published their phone number publicly on forums, websites, or classified ads, search engines have no indexed records for it.
2. **Social Media Privacy Restrictions:** Platforms like Facebook, Instagram, and LinkedIn actively disallow search engines from indexing user phone numbers to comply with data privacy standards.
3. **OSINT vs. Contact Harvesting (Truecaller):**

| Feature | PhoneInfoga (OSINT) | Truecaller (Aggregator) |
| :--- | :--- | :--- |
| **Data Origin** | Public web crawlers, search engines, open APIs | Crowdsourced private mobile address books |
| **Private Personal Numbers** | No results unless publicly posted | Displays names via crowdsourced contact lists |
| **Privacy & Ethics** | 100% compliant with public open data | Uploads user contact lists to private servers |
| **Primary Use Case** | Cyber investigations, fraud & scam analysis | Daily caller identification & spam call filtering |

## 🔌 Available Scanners

* **`local`**: Offline parsing using international telecom datasets (Country, formatting, validity, carrier).
* **`googlesearch`**: Generates high-accuracy Google Dork links for social profiles, spam lists, and public documents.
* **`numverify`**: Live query via the Numverify API (requires API key in `.env`).
* **`googlecse`**: Programmatic search via Google Custom Search Engine (requires API key & engine ID in `.env`).
* **`ovh`**: Telecom provider lookup for supported regions.

---

## ⚙️ Optional API Configuration (`.env`)

To enable third-party scanners (Numverify, Google Custom Search), create a `.env` file in the project root:

```env
NUMVERIFY_API_KEY="your_numverify_api_key_here"
GOOGLE_CSE_KEY="your_google_cloud_api_key"
GOOGLE_CSE_CX="your_custom_search_engine_id"
```
